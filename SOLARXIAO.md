# SolarXiao firmware has moved

The SolarXiao Advanced E22P build and documentation now live in the private repository [KF7R/solarxiao-meshtastic-firmware](https://github.com/KF7R/solarxiao-meshtastic-firmware).

The new build preserves the SolarXiao board settings and reports **XIAO_NRF52_KIT (88)** with target **seeed_xiao_nrf52840_kit**. It includes a USB UF2 and an application-only BLE DFU ZIP for S140 7.3.0.

[Download the verified USB/BLE package](https://github.com/KF7R/solarxiao-meshtastic-firmware/actions/runs/38025685865/artifacts/11660134541).

The SolarXiao build and packaging workflows have been retired here. Historical commits and build artifacts remain available in this repository.
